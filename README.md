# Fatima FSK Portfolio — V9 Living Archive

Multi-page static portfolio for Fatima FSK. All files intentionally live in this single folder for direct GitHub upload.

## Pages
- index.html — Home
- about.html — About / journey
- books.html — Books + literary event galleries
- writings.html — Articles and essays
- speaking.html — Speaking, Human Library and recognition
- ideas.html — Ideas / thought themes
- impact.html — Philanthropy and community impact
- media.html — Press coverage and public moments
- contact.html — Contact

## Updating content
Core repeatable content lives in `content.js`. Add new articles, press coverage and impact items there. Page-specific editorial features can be added to their corresponding HTML page.

## WordPress writing hub
Update `wordpressBase` in `content.js` when the external WordPress publication site is ready.

## Mobile
V9 adds stronger 24px edge safety on small phones, reduced heading scales, overflow protection, responsive galleries, and a solid blurred navigation background so the fixed menu remains readable over every section.
